# Agent 105 avro2ddl — 消息 Schema 建表

日期: 2026-10-31 分支: fresh

## 内容

- 脚手架起步。`agents/data/avro2ddl/`：converter（纯 JSON 解析,零新依赖）、i18n、report、advisor_llm（可选落地评审）、api、tools、manifest（group build, /avro2ddl）。
- 类型映射：Avro 原语直映（long→BIGINT、bytes→BINARY/STRING）;**logicalType 优先**（decimal→DECIMAL(p,s)、date→DATE、timestamp-millis/micros→TIMESTAMP/DATETIME）;[null,T] 解包为可空;多类型 union 落 STRING 并点名有损;enum→STRING 且取值集进 COMMENT;Hive 出真 ARRAY/MAP/STRUCT,Doris 复杂类型落 JSON 并给 DUPLICATE KEY/分桶桩;doc→COMMENT。JSON Schema 侧:integer/number/boolean 直映,string+format（date/date-time）对号,object/array 有损点名。
- 回检守卫：DDL 经 schema_drift 解析器回检同列数才返回。
- 三连闭环：topic_schema 对比两版消息 Schema → 本 agent 把一版落成表 → seatunnel_gen 把表变成同步作业。
- CLI `avro2ddl`（-f/--text/-t/--dialect hive|doris/--ddl-out 另存/--llm）。
- 测试：`tests/test_avro2ddl.py` 11 项（双方言映射/logicalType 优先/有损计数/回检列数/JSON Schema flavor/表名覆盖/ddl 另存）;页面 spec 2 项。
- 示例 `examples/avro2ddl_demo/order.avsc`（decimal/enum/可空/数组/时间戳/多类型 union 齐打）。
