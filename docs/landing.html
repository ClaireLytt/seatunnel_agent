02能力桶

全库同步生成器

introspect 源库或离线 DDL，批量生成每表同步配置 + 目标端建表 + PII 脱敏注入。syncgen --fail-on pii 把"未脱敏任务"挡在 CI。

Chat BI 问数

指标语义层口径白名单、确定性归因分解（"为什么跌了"→ 各维度贡献恰好加总）、 混合检索 + 56 题基准回归门。

SQL 评审 × 血缘

静态 linter + 15 项清单语义评审，表/列级血缘，--diff 只看增量、 SARIF 上报 Code Scanning。

运维三件套

日志根因聚类、Schema 漂移分级（可生成迁移 ALTER）、分区 SLA 延迟订阅 —— 飞书卡片告警，安静时不打扰。

成本与口径

审计日志聚出 Top 烧钱查询模板与缺分区过滤 offender；两个报表对不上？ reconcile AST 级指出口径差异。
